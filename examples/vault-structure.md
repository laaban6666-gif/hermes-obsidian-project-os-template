# Example Vault Structure

A sanitized Obsidian vault layout for AI-assisted project operations.

```text
00_Command/
  AI Team Operating Rules.md
  Daily Review Checklist.md

10_Projects/
  Project A.md
  Project B.md
  Public Template Project.md

20_Business/
  Customer Hypotheses.md
  Pricing Notes.md

30_Templates/
  project-note.md
  decision-log.md
  pr-readiness.md
  cron-job-spec.md

40_Runbooks/
  Local Secret Scan.md
  GitHub Publication Review.md
  Incident Triage.md

50_Decisions/
  2026-06-06 Choose Project OS Template.md
  AI Team Routing v1.md

90_Archive/
  Completed Project.md
```

## Naming tips

- Keep active projects in `10_Projects/`.
- Keep reusable decisions in `50_Decisions/`.
- Put operational procedures in `40_Runbooks/`.
- Archive instead of deleting when possible.

## Privacy tips

- Do not paste raw chat logs that include secrets.
- Prefer summaries over screenshots.
- Keep account-specific values out of public notes.
- Use placeholders for IDs and URLs until publication review.
