## Short project description

Hermes x Obsidian Project OS Template is an open-source starter kit for running AI-assisted projects with Obsidian project memory, AI-team routing, decision logs, PR readiness checks, cron-job documentation, and security-first publication boundaries.

It helps solo founders, small teams, and maintainers turn scattered AI chats and private notes into a repeatable operating system that is safe to share and review.

## Why the project matters

AI-assisted development can create speed, but it also creates coordination and safety problems: unclear decisions, hidden assumptions, accidental secret leakage, and risky automation. This template gives small teams a lightweight way to document what the AI should do, what it must not do, how work is reviewed, and what requires human approval.

The project is intentionally practical and reusable. It includes templates for project notes, decision logs, PR readiness, AI-team routing, and scheduled-job specs, plus sanitized examples that users can copy into their own Obsidian vaults.
