# Starter Vault

This directory is an Obsidian-ready starter vault. Open it directly in Obsidian with **Open folder as vault**.

## Start here

1. Open `00_Command/AI Team Room.md` to coordinate the next AI-assisted task.
2. Duplicate `10_Projects/Sample Project.md` for your project.
3. Copy templates from `30_Templates/` when you need a new project note, decision log, PR readiness check, or scheduled job spec.
4. Use `40_Runbooks/PR Readiness Checklist.md` before merging, publishing, or asking for review.
5. Move completed or paused notes into `90_Archive/`.

## Folder map

```text
00_Command/       Operating rules and AI team coordination
10_Projects/      Active project notes
30_Templates/     Reusable note templates
40_Runbooks/      Repeatable operating checks
50_Decisions/     Decision records
90_Archive/       Completed or paused work
```

## Public-safe rule

Keep this vault generic unless it is private and intentionally managed. Do not add secrets, customer data, private account identifiers, or non-public credentials.
