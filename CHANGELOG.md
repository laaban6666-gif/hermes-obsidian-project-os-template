# Changelog

All notable public changes to this project are documented here.

This project uses semantic versioning for template documentation and starter-vault packaging. A version entry may describe planned release contents before a GitHub Release or tag exists; release publication should be confirmed separately in GitHub.

## [0.1.0] - Planned v0.1 starter package

Status: **prepared in documentation; not yet published as a GitHub Release by this change**.

### Included

- Public-safe Hermes x Obsidian Project OS starter vault under `starter-vault/`.
- AI Team Room and AI Team Routing notes for coordinator, implementer, reviewer, and human approval handoffs.
- Reusable templates for project notes, decision logs, PR readiness, AI team rooms, routing, and cron job specs.
- Sanitized examples, including sample project notes, sample PR readiness, profile routing, vault structure, and an end-to-end OSS docs walkthrough.
- Privacy-safe visual tour with generic SVG diagrams instead of private screenshots.
- GitHub issue templates and pull request template for public OSS collaboration.
- Publication and release packaging documentation for maintainers.
- `VERSION` file identifying the current documented package version.

### Safety notes

- The starter content uses placeholders and generic examples only.
- Maintainers should run the publication and release checks before publishing a repository ZIP, starter-vault ZIP, tag, or GitHub Release.
- Do not add private notes, real account identifiers, credentials, customer data, or unsanitized screenshots to release assets.
